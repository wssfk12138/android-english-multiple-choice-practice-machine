## 来源与许可边界

两份包分别是考生回忆版真题整理和英语刷题机本地题库导出，均明确标注为非官方内容。包内包含题目、选项、标准答案和（英语二）已锁定的 AI 标签；不包含 API 配置、API Key、聊天、练习记录、错题本、单词本或完整本机路径。

`manifest.json` 当前使用 `NOASSERTION`，表示程序不会替题库内容主张统一许可证。重新分发前，请核对原始来源、考生回忆版的传播边界和目标地区的法律要求；程序代码的 `GPL-3.0-only` 只适用于代码本身。

## 发布前核验

维护者应在发布前重新计算文件哈希，确认包内清单与 README 一致，并使用当前 Android ESQ 导入器做一次预览、冲突检查和批准入库测试。题库包不应被替换为包含个人学习数据的 SQLite 数据库或导出文件。
