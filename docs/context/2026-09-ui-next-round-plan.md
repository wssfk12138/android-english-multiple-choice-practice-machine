### 2.1 已复现的确定缺陷

**B1 配置行尾“更多操作”菜单被卡片裁切（CONFIRMED，本轮最严重）**

- 证据：`05-menu-open.png` / `05-menu-open.xml`。
- “…”按钮 `新 API 配置 更多操作` = `[2397,754][2484,843]`；其定位祖先 `.api-more` 只有约 6px 高。
- 菜单容器 `[2154,847][2475,973]`，唯一菜单项“删除配置” `[2169,862][2460,960]`。
- 第三张卡片实体下边缘实测 y≈890（卡片 `546..2490 × 703..890`，高约 187px）。
- 裁切量：菜单容器可见 `847..890` = 43/126px（**34%**）；菜单项可见 `862..890` = 28/98px（**29%**）。“删除配置”的文字完全落在裁切区内，截图上该位置只有一条白色圆角空白条（采样 y=860–880 全为纯白，无文字像素）。
- 根因（源码事实）：`frontend/src/styles.css:640` 的 `.api-profile-card { overflow: hidden }` 与 `styles.css:693` 的 `.api-more-menu { position: absolute; top: 44px; right: 6px }`。定位容器在卡片内，菜单下移 44px 后必然越出卡片底边，被 `overflow:hidden` 整段裁掉。
- 用户描述与实机一致。
