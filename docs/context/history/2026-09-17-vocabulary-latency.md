# 2026-09-17 单词本性能修复回执

## 结论与范围

用户明确指出单词本打开慢和每日一背三评分按钮切词慢，要求保留原配色，由助手通过无线调试测试。已完成两项最小修复及手机/平板隔离诊断对照。数据读取是已证实的卡顿贡献因素，不再沿用早期“竖屏流畅所以数据读取不是主因”的推断。没有更改主题 CSS 或取消模糊材质。

当前正式包平板为 alpha.90、手机为 alpha.89，均通过 dumpsys package 复核，未被本次诊断安装覆盖。测试使用 09-13 私有数据库快照的副本，共 216 词、初始 155 到期词；关闭诊断副本模型配置和 LAN 自动同步，评分只写隔离副本。不是最新正式库数据，也不是 release 性能基准。

## 修复与保护

1. VocabularyView 原先每次正式评分前都读取完整到期队列及出处；现在有 review_revision 时直接进入原有事务保存，由存储层校验版本。旧后端无版本字段时保留原预读。404/409 刷新并要求重新查看评分；其他保存失败保留当前词。重复点击、离页、迟到响应保护保留，不提前假装保存成功。
2. Android 浏览列表使用 projection=summary，仅取列表显示字段；有常用释义时不读出处、词形和记忆内容。需要出处释义兜底时继续验证来源。limit=all 的复习/巩固仍读完整词条，Windows 请求不增加投影参数。列表及统计复用一次捕获的题库范围。
3. 两个现有测试文件增加正常评分不全量 GET、冲突/删除/保存失败、摘要字段、真实出处失效、范围、分页与搜索断言。评分事务和算法未更改，没有数据库迁移或 ESQ 格式变化。
