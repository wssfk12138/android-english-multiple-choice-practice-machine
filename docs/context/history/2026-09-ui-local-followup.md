本轮仅本地源码、合成数据测试和前端构建。禁止真机验证；未连接设备、安装 APK、访问真实复习数据或调用真实模型。单词本卡顿继续暂挂，启动、队列、评分事务和预取逻辑未修改。未提升内测版本号，未同步其他仓库或发布。

## 实现

- 题库配置移除独占图标，首页两个模板统一提供管理、回收站和查看全部题库；题库列表将批量操作并入工具栏。窄屏合理换行，修复竖屏管理面板被旧 CSS 隐藏。
- 单词本筛选默认折叠，摘要和选项显示数量。详情与复习共用内容组件，常用释义与词性常驻，语境、原句/模型例句、词形、辨析等分层折叠，窄屏一次只开一层，旋转后自动收敛；保留原句来源与本地形近词标签，操作保持底部。
- 按新增反馈，详情与复习长词标题按实际宽度自动缩字号、保持单行，换词及旋转后重新适配。最低 14px，极端长输入可横向滚动查看全文。评分保存期间三按钮禁用防止重复点击，文字和横排位置不变。
- 错题分析移入更多菜单，点击后收起；模型高级参数与系统提示默认折叠；同步连接、目录、更新独立折叠，类别与操作状态响应式两栏。诊断页压缩说明，保留数据导出提示、结果与错误。
- 单词、错题、题库目录、同步类别和显示设置统一 checkbox/radio 的选中、焦点和禁用态；题库批量选择可实际切换。
- 设置增加持久化的“翻译时补全词形与例句”开关，默认开启。同一次翻译请求携带开关快照并要求中文词形标签；关闭时保留已有词形与例句。移除常驻独立补全按钮，失败重试仍走原后台队列，并保留并发和手动释义保护。
