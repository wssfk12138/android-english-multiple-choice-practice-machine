# 做题记录：下一阶段备选开发计划

> 状态：候选方案，未启动开发。需求收口日期：2026-09-09。
> 本阶段仅核查与编写计划，不修改程序、数据库、版本、构建或安装产物。后续须由用户明确选择启动；本文件不是跨仓同步、提交或发布授权。

## 1. 目标与最终范围

用户在当前题库配置下查看已完成练习，按题目归拢多次记录；点击一次记录，回到该次判分后的只读题面。列表展示汇总指标，不展示逐题对错、用户逐题选项或标准答案。

以下规则以用户最后一轮回复为准，取代早期“整套过程中的单篇记录和整套汇总同时归档”的建议。

| 场景 | 是否进入做题记录 | 归档粒度 |
| --- | --- | --- |
| 整套练习，最终整卷提交成功 | 是 | 一次整套记录 |
| 整套过程中提交一篇，整卷尚未提交 | 否 | 仅保留现有练习进度和判分 |
| 所有篇目分别提交，但未最终整卷提交 | 否 | 仍须完成最终整卷提交 |
| 明确的单篇随机练习，最终提交成功 | 是 | 一次单篇记录 |
| 未完成、放弃、空会话、提交失败 | 否 | 不创建历史记录 |
| 错题重练、错题历史重练、任意篇目组合、多篇随机练习 | 否 | 不纳入首期范围 |
| 同步为外键依赖生成的占位会话 | 否 | 永不作为真实练习展示 |

“完成”沿用当前最终交卷的成功判分语义，不新增“必须每道题填满才能交卷”的规则；漏答继续按现有评分处理。整套回放可以切换篇目查看结果，但这些篇目不是独立历史条目，不计入记录数量。

单篇资格必须由启动入口的明确意图加实际单篇范围共同确定，不用“会话碰巧只有一篇”推断。当前 Android 首页随机听力使用 `selection_scope=paper_unit_type`，属于整套题型随机，不计作首期单篇记录；不为本功能新增听力练习模式。以后若已有明确单篇听力入口，可按相同资格规则展示“听力第一篇”。

## 3. 信息结构与排序

- 页面严格跟随题库界面当前选中的配置；页头显示当前配置名称，不另设独立配置选择器。切换配置后重新查询并隔离缓存。
- 采用两级结构：第一级为“整套试卷”或“具体篇目”，第二级为该对象的历次练习。整套与单篇可在同一列表并列，也可用紧凑的全部/整套/单篇筛选。
- 整套组显示“2024 年 · 英语（一）”；单篇组显示“2024 年 · 阅读第一篇”，辅以所属试卷，避免名称相同无法辨认。
- 分组键使用配置及试卷/篇目的稳定身份；题名仅用于显示。不同配置中同名同题仍独立，重导入产生新身份时不按名称合并。
- 默认全部折叠；组头展示名称、记录次数、最近完成时间及最近一次得分。首次进入或切换配置全部折叠；从回放返回恢复之前展开状态、排序、筛选和滚动位置。
- 排序提供“完成时间”和“题目年份”，默认完成时间从新到旧，允许切换升降序，不提供得分排序。
- 完成时间排序：组按最近一次完成时间排序，组内记录按所选时间方向排序；年份排序：组按题目年份排序，同年按最近完成时间倒序，组内固定按完成时间倒序。缺少年份置后，相同值用稳定身份打破并列，分页不跳项。
- 完成时间存储为明确时区的时间值，按设备本地时间显示；紧凑行显示到分钟，详情保留完整日期时间。跨日、跨年记录不只显示“今天”或“昨天”。
- 列表与分组内记录分别分页或按需加载，不一次读取全量题面快照；计数只计算符合归档资格的记录。

## 4. 布局与交互

复用各版本现有错题本和题库的字体、配色、展开图标、分隔线与控件样式。中等信息密度，以列表行组织内容，不增加巨幅标题、统计大卡片或固定空白详情栏。

### 电脑及 Android 横屏

左侧导航保留独立“做题记录”，放在错题本附近。主区占用可用宽度；不为了回放预留空白右栏。

```text
               > 2023 年 · 阅读第一篇       2 次  最近 09-08 18:10

               v 2024 年 · 英语（一）       3 次
                 完成时间            得分       正确率   用时
                 2026-09-09 20:35    72/100      72%    48:16  >
                 2026-09-07 19:02    65/100      65%    未计时 >
```

### Android 竖屏

沿用运行时方向状态，手机和平板竖屏均从“笔记”进入做题记录，不挤入底部独立导航。笔记内入口与错题本同级。

```text
< 笔记          做题记录
考研英语（一）
全部 ▾                   完成时间 ▾ ↓
--------------------------------------
> 2024 年 · 英语（一）          3 次
  最近 09-09 20:35           72/100
```

示意数字仅用于布局。长题名最多两行；完整名称在组展开或回放标题中可访问，不能依赖移动端悬停。得分与时间不被题名挤掉；指标使用稳定列位，窄屏自然转为两行，不以缩小字体硬塞。用时始终有位置：`未计时`、`未记录`均保留该位置。

整行记录可点击；展开箭头只切换分组，避免误进入回放。触控目标建议至少 44 CSS px，支持键盘焦点及清晰的展开状态。空列表只用简短占位，无全屏空白宣传区；加载、失败重试、来源已删除和旧记录受限均有对应状态。

## 5. 计时、分数与历史回放

### 计时基线

- 只记录整次合格练习的计时器累计值，不记录每篇时间，不通过完成时间减开始时间推算。
- 用户启动才计时，手动暂停不累计，整套过程中单篇提交不结束整套计时。明确单篇随机练习在最终提交时结束本次计时。
- 最终确认提交时冻结候选用时，成功时与归档一并保存；网络/处理耗时不进入作答时长。失败时不生成历史，恢复可继续作答的计时状态，不能丢失此前累计值。
- 新会话明确区分未启用计时、已计时（含真实零值）、历史未知；计时草稿落入可恢复存储，localStorage 仅为兼容来源，不能成为新记录唯一依据。
- 首期不改变现有前后台自动暂停行为。用户没有明确确认上一轮建议的“后台自动暂停、返回手动继续”；该项为独立可选改进，不作为本计划阻塞条件，也不能宣称当前计时能检测用户是否真的在操作。旋转不能增加时长、丢失状态或重复结算。

### 汇总口径

得分/满分取当次判分结果；正确率按当次可判分客观题的正确题数除以总题数，漏答按当前判分规则处理，不用得分百分比替代正确率。展示精度沿用现有判分页，有加权分值时两者可以不同；无法还原的旧指标不猜测。

### 回放行为

- 打开独立只读回放路由，复用判分组件和样式，不直接进入仍允许操作的旧练习路由。页头展示完成时间、得分、正确率、用时以及“历史记录”状态。
- 展示当时题面、篇目顺序、选项顺序、用户选择和判定对错；整套允许切换篇目。遵守当前答案隐藏边界，不增加标准答案键或新解析权限。
- 不允许改选、提交、启动计时，不写作答事件、错题统计或新记录。组件挂载与页面离开也不得触发这些副作用。
- 显式“重新练习”才进入新的作答流程并生成独立会话；仍遵守现有活动会话提示，不偷偷放弃未完成练习。取消重新练习不产生会话。
- 返回列表恢复位置。Android 系统返回键、页内返回与横竖屏旋转行为一致；直达链接缺少返回状态时回当前配置历史页。

## 6. 数据与服务方案

具体表名和接口名在实施时按四树现有约定确定；下列字段语义与事务要求固定。

| 数据对象 | 主要内容 | 约束 |
| --- | --- | --- |
| 会话来源 | 明确练习意图、原始选择范围、配置与源试卷/篇目稳定身份 | 创建时固定，不能只凭 mode 或最终篇目数量猜测 |
| 历史摘要 | 稳定记录 ID、源会话 ID、整套/单篇类型、完成时间、分数/满分、题数/正确数、计时状态及毫秒、快照版本 | 一次会话最多一条；索引支持配置/年份/时间和分组查询 |
| 回放快照 | 当时题面、选项、顺序、用户答案、判定与分值、题名/年份及媒体引用 | 不随题库编辑重新判分；不得额外暴露答案键 |
| 来源绑定 | 稳定 profile/paper/unit 标识及删除关联 | 删除、恢复、移动和同步均可追踪，不按名称匹配 |

建议采用独立历史摘要和快照存储，关联现有会话；不把现有 `practice_unit_submissions` 直接当作历史列表。新练习创建时固定该次题目与判分依据，续做只读取已有版本，不在每次加载时重新抓取题库覆盖；对前端仍保持答案隐藏。过程单篇判分保存已判结果，最终交卷归档整套视图。快照不是单独对外可见的过程记录。

最终交卷应在同一事务内完成判分、会话完成状态、已有错题账本更新和历史归档，任一步失败全部回滚；以源会话稳定 ID 唯一约束保证重复提交、超时重试和重复同步不重复归档。已判单篇按原结果汇总，不在整卷交卷时因答案后改而重新判定或重复累计错题。实施前复核现有重判链路，以定向测试约束改变。

服务提供分页分组摘要、组内历次记录、单条回放三个只读能力；每次均校验当前配置及来源存活状态，不能只在前端过滤。切换配置时取消或丢弃旧请求结果。记录数、排序键、正确率及详情使用相同过滤口径。

题库内容是外部输入，快照渲染沿用现有安全组件及资源访问限制，不引入未经处理的 HTML 注入路径。图片/音频采用既有资源管理；有历史引用的资源不应因题目编辑被清理，最终来源删除后仅回收确无引用的资产。媒体缺失明确提示，不能用新的媒体静默替代。

## 7. 删除、恢复与题库隔离

- 沿用七天回收站：删除试卷/配置时，相关历史和错题本一起不可见；恢复时一起恢复；永久删除或到期清理时一起删除。
- 试卷删除、批量删除、整个配置删除、永久删除四类提示都明确关联影响。示例：“将所选试卷及其对应的做题记录、错题本内容一并移入回收站，7 天内可恢复。”永久删除提示明确无法恢复。
- 查询不能仅依靠历史表自身删除标记；来源在回收站中时，直达回放和统计都不得绕过隐藏。恢复后身份和结果保持原样。
- 首期没有跨试卷组合历史，因此不需要拆分组合记录或重算过去总分。任何旧复合会话不为凑齐历史而拆成单篇。
- 题库复制或重新导入默认不复制个人记录；同名不合并。现有“移动试卷”操作让绑定记录随源试卷进入目标配置，原配置不再展示，保留历史题名快照；不混入目标已有同名对象。
- 若编辑操作实际删除并重建篇目，须在实施前按其稳定身份规则核验并提示影响；不得让外键级联悄悄破坏可回放记录。普通内容修改保留既有快照，源试卷/配置删除才执行已确认的深度绑定。

## 8. 存量数据与同步

### 旧数据

增量迁移，不清空现有会话、答案、错题账本或用户库。旧整套只有完整最终提交证据才纳入；旧随机记录缺少明确单篇启动范围时不自动认定。能确认资格但缺少当时题面的记录标记“旧记录，部分历史信息未保存”，可展示可靠摘要；不能完整回放时明确受限，不把当前题面包装成当时快照。

旧计时仅在同设备保存状态能与会话可靠对应时采信；否则“未记录”。不从错题累计次数伪造历史记录，不从单篇提交补造整套完成。迁移可重复执行且不生成重复行。

### 局域网同步

新增摘要、快照和计时归入现有“做题记录”类别，沿用配对、权限、配置隔离、稳定身份映射和删除墓碑。与错题本类别分开，错题依赖占位会话始终排除。

- 已完成记录及其快照作为一致的不可变单元合并；同一记录跨设备不重复，不累加两端用时。不同记录 ID 的真实独立练习各自保留。
- 同一活动会话两端并发完成时沿用现有确定性冲突规则，整包选择同一结果，不拼接分数和题面；测试回放与选中的会话状态一致。
- 新旧端通过能力/版本检查处理未知字段和缺失快照，不让旧端回写清空新端历史。无法保证兼容时明确要求升级后同步本类别，不静默损坏。
- 快照按记录或受支持的批次分段传输，验证单条体积、整体请求上限、失败重试及游标不前进；大媒体复用资源机制，不直接塞入学习行。
- 来源缺失时先建立允许同步的题库身份映射，再合并历史；不创建跨配置孤儿。删除墓碑阻止旧设备复活已永久删除记录。
- ESQ 继续仅承载题库，不加入用户作答快照与计时。

## 10. 核心验收矩阵

| 类别 | 必须验证的行为 |
| --- | --- |
| 准入 | 整套中提交一篇无记录；全部单篇提交但未整卷交卷仍无记录；整卷成功仅一条；明确单篇随机成功一条；其他模式和占位会话为零 |
| 可靠性 | 重复点击、网络超时重试、事务失败、程序重开不重复/不丢已成功归档结果；失败不留下半条记录 |
| 评分 | 加权得分与正确率各自正确；漏答/零分/小数分；过程判分不被最终提交重新覆盖，错题次数不重复 |
| 计时 | 未计时、真实零值、暂停/继续、多次恢复、提交延迟与失败、旋转；历史未知不被误标为零或未计时 |
| 回放 | 改题名、正文、选项、答案后旧回放不变；选项乱序仍对应；只读访问数据库无作答/错题副作用；不泄露标准答案 |
| 分组 | 同名不同配置/不同篇目/重复练习分别正确；折叠初态；两种排序及并列/空年份；分页无重漏 |
| 范围 | 切换配置时旧请求不污染新页；直达链接和来源移动/删除后权限及可见性正确 |
| 生命周期 | 单套/批量/配置删除一起隐藏；恢复一致；永久/到期清理正确；同步墓碑不复活；共享资产不误删 |
| 兼容 | 合成旧库升级幂等；无法确认资格的旧随机记录不伪造；两端重复同步、断线、权限关闭、旧端回写及并发判分不混合结果 |
| UI | Windows 常用尺寸与缩放；Android 手机/平板横竖屏和旋转；长标题、长配置名、空列表、大记录集、未计时均无遮挡和大块浪费 |
