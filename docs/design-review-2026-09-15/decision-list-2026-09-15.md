# 待用户决定事项清单

| 事项 | 选项 | 建议 | 影响 | 可回退 | 当前默认建议 |
|---|---|---|---|---|---|
| 额外巩固以下布局 | A 紧凑；B 平衡；C 学习辅助 | B | B 兼顾密度和理解；A 最短；C 最长 | 是 | B |
| 额外巩固初始状态 | 展开；折叠后点击 | 展开 | 展开能直接开始练习；折叠更清爽 | 是 | 展开 |
| “我的卡片”语义 | A 改名保留个人记录区；B 保留“笔记”语义；C 本轮隐藏展示 | A 或 B 需产品确认 | 只影响名称和理解，不应丢失 note 数据 | 是 | A：显示名称为“我的卡片” |
| 竖屏详情交互 | 保留 accordion；独立详情页/底部抽屉 | 保留 accordion | 维持现有响应式习惯，改动小 | 是 | accordion |
| 模型目录默认状态 | 折叠但筛选常驻；默认展开 | 折叠但筛选常驻 | 降低首屏长度，同时保留发现入口 | 是 | 折叠 |
| 回填策略 | 保留自动/手动；改为明确手动；增加最近结果状态 | 保留现有语义，是否显示结果状态待定 | 影响操作预期和反馈，不应未授权改后端策略 | 是 | 保留现有语义 |
| 性能调查时机 | UI 后设备 profiling；先性能后 UI；维持现状 | UI 确认后 profiling | 决定后续工期和是否调整 blur/SQLite/队列 | 是 | UI 后 profiling |
| 开始实施边界 | 仅设计确认；允许改源码；另行授权构建安装 | 设计确认后改源码，构建等另批 | 影响代码、设备和发布流程 | 是（源码可回退） | 当前不改源码 |

每项选择都可以在实施前调整；构建、安装、提交、推送、跨仓同步和发布不会因选择 UI 方案而自动获得授权。
