# UI 设计规格

## 共享规范
- 目标视口：横屏 1205×721dp、竖屏 753×1173dp、手机 390×844。
- 控件最小触控高度 44px；卡片圆角 8–12px；统一边框、行高和间距 token。
- 蓝/灰中性体系，明暗主题共享结构；窄视口自动换行，不产生横向滚动。

## 页面
- 单词本：上半区顺序固定为标题、统计 chip、搜索/筛选、额外巩固；下半区按 A/B/C 方案切换。
- 每日复习：小标签、词标题与音标、常用释义、左对齐真题原句引用框、评分按钮。
- 单词显示：11 项独立开关；标题保留音标，共同释义去重。
- 设置：首页直接展示外观；单词本卡片提供历史回填入口。
- Model/API：行内标签、同一操作行、菜单脱离 overflow 裁切、目录筛选常驻。
- 导入：导入目标、草稿校对、智能标注范围三段式。
- 更新/同步/诊断：保持现有真实动作，用状态、筛选和操作分组表达。
- 错题本、练习、AI 助手：展示列表、练习入口和空状态。

## 单词本下半区
- A 紧凑列表：突出单词、状态、操作，屏幕更短。
- B 平衡列表（推荐）：单词、简短释义、状态兼顾扫描和理解。
- C 学习辅助列表：增加音标/释义，信息更丰富但更长。
上半区三种方案完全一致；“额外巩固”默认建议展开。
