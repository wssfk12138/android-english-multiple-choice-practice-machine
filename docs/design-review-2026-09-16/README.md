## 已确定的边界

- 单词本只重新设计“额外巩固”以下。上方维持当前信息顺序、入口和功能，只允许微调间距；历史补缺移走、重复筛选合并、解释性小字删除属于此前明确要求的例外。
- 单词显示采用 **B 三组方案**，保留现有 11 个字段，保留“我的笔记”开关、编辑和已存数据。你最后说的“我的卡片”不再按早先删除意见执行；是否改名称列为 D05。
- 每日一背的真题原句改为小标签、左对齐引文和出处；删除“常用释义”标题附近重复的音标、词性标记，保留单词下面的独立音标。词形字段本身不删除。
- 设置首页直接切换深浅色；侧栏夜间切换继续保留。历史词条补缺管理进入设置的设备与维护分组。
- API 更多菜单完整显示；名称、协议、地址采用紧凑同行标签；删除重复标题；模型筛选、默认模型、推理强度、保存与测试在空间足够时同排，窄屏自然换行；模型目录的搜索和显示状态筛选可见。
- 删除的是标题后解释标题的小字，例如“额外巩固不改变正式复习计划，可反复练习”。不批量删除释义、出处、单位、数量、运行状态、错误和操作后果。
- 本轮交付只增加设计材料与预览，不修改应用源码、不构建或安装、不更改数据库、不暂存提交、不同步 Windows 或公开仓库。

## 整改分三层

### 第一层：明确问题，直接纳入选定设计后的实现

| 项目 | 本轮判断 | 设计与完成标准 |
| --- | --- | --- |
| API 省略号菜单被裁 | 当前卡片裁切属性与内部绝对定位菜单构成直接证据 | 菜单脱离裁切层、靠边自动调整；展开和收起的配置都验证，最后一项可点击 |
| API 表单过宽和标题重复 | 原始截图与当前模板一致 | 保留全部字段和管理入口；常用操作靠近默认模型；不依靠缩小字体挤成一排 |
| 模型目录筛选难发现 | 筛选已经存在，藏在折叠区；不是缺少实现 | 把搜索和全部/已显示/已隐藏放到目录顶部，初次进入即可找到 |
| 复习答案居中和信息重复 | 原始要求、每日一背截图、共享组件可互相印证 | 单词区可居中；答案区始终左对齐；独立音标只出现一处，出处跟随原句 |
| 单词列表空间利用差 | 历史截图显示明显大行距；不直接承诺固定增幅 | 选定 D01 后用实际字体、长词和窄屏验证；状态可见、点击目标足够、详情不丢失 |
| 设置入口绕路 | 设置首页现为二次入口 | 首页直接切主题，保留侧栏入口；单词显示按三组重排且旧设置不重置 |
| 维护任务干扰学习页 | 补缺状态条位于单词本顶部 | 移至设置保留暂停、继续、失败重试、配置缺失提示和错误；移入口不等于停止后台任务 |
| 解释小字、控件高低不一 | 按页面逐项核对，不按字体大小删除 | 执行 UI 说明中的文字保留表；同一按钮行按最高内容对齐，字号放大可增高 |

### 第二层：首次载入与复习卡顿，先取得设备证据

现有日志给出可靠的源码线索，但没有足够的分段设备测量证明唯一根因。当前单词本仍存在打开时触发翻译、随后加载列表和状态刷新的路径；列表包含宽字段和出现记录读取。首页涉及刷新、学习待办及启动准备事件。具体是否占据卡顿的大头，应测后决定。

| 检查对象 | 需要的证据 | 达到什么条件再改 |
| --- | --- | --- |
| 首页刷新和重复读取 | 冷启动、首进、再次进入的请求时序、刷新次数、每段耗时 | 确认重复工作及其成本，且合并不丢启动后的新数据 |
| 单词本前台与后台竞争 | 列表读取、详情、待背队列、翻译启动、补缺状态写入分别计时 | 后台任务确实阻塞首屏时，再考虑延后启动或调整顺序 |
| SQLite 与原生桥 | 平板上实际查询、排队、序列化、返回数据量 | 不拿 PC 数据库耗时代替 Android，不把所有等待都归因 SQL |
| 宽字段和出现记录 | 实际词条数、字节数、解析及渲染耗时 | 能证明列表只需轻字段时再拆列表/详情；保持详情和复习完整 |
| 模糊和合成层 | 同一设备同场景关闭/开启效果的帧时间对照 | 测出改善后再减效果；当前只是风险假设，不称已确认 GPU 根因 |

建议每个场景至少重复 3 次，记录原始值与中位数；首屏“能看见”和“能点击”分开。目标是消除测得的主瓶颈，不预先承诺毫秒降幅。是否与 UI 实现并行做测量见 D11。

### 第三层：全页面一致性与功能回归

范围覆盖首页、题库、错题、单词本/复习/编辑、设置、单词显示、维护、API/密钥/目录、导入/草稿/标注、做题、AI 助手、更新、同步、诊断、回收站、帮助。

以浅蓝主题、白色实体面板、克制分组、统一按钮和左对齐表单为基调。页面原有功能为边界，不顺手增加打卡、排行榜、音频、额外学习计划或新的数据库字段。导航和全局品牌在预览中只作定位示意，不据此扩大导航改造范围。

| 阶段 | 修改范围 | 必要验证 | 停点 |

| 1 高频学习与设置 | 共享单词内容、单词本下半区、复习卡、显示设置、设置首页、维护入口 | 旧设置、笔记、复习评分和维护控制不回退；针对相关现有测试；构建前端 | 可验收成果形成后再安排本地版本保存，提交仍单独授权 |
| 2 API 配置 | 弹层、表单、模型选择/强度、密钥、目录 | 新建/编辑/停用/删除、无密钥、协议切换、不可用模型、保存失败、连接失败 | 明确无裁切与功能遗漏后进入通用页面 |
| 3 其余页面 | 按 UI 覆盖表整理布局与冗余标题说明 | 每页主操作可达、危险操作后果可读、长文本与空错误状态 | 不趁统一样式改业务规则 |
| 4 Android 验收 | 选定版本的设备验证 | 真实 WebView 视口、横竖屏、旋转、键盘、返回键、深浅色、系统字体放大、长内容；有关联才测对应流程 | APK 构建安装需你明确选择；预览验证不代替此项 |
| P 性能（可并行测量） | 只针对测量证实的热点 | 同设备同数据前后对照，校验结果一致、无新首屏阻塞 | 无设备证据时保留未验证状态，不顺手重写数据层 |

文档设计交付不需要应用全量构建。进入实现后按相关范围运行既有测试；涉及原生或 APK 才走项目 RUNBOOK 的前端构建、Capacitor 同步、Gradle 链路。发布、通道更新、推送、跨仓同步均不包含在选择布局里。

## 风险与回退

最需要保护的是个人记录、已保存显示配置、正在进行的复习、模型密钥和题库草稿。布局改动优先不改变存储格式；使用现有键和组件接口。条件性折叠只改变展示，不能把字段数据丢弃。字体放大时允许换行和增高，不能为了齐整裁字。
