## 本轮尺寸与布局要求已确认

1. 每日一背：以本轮修改前预览为基准，卡片宽、高各缩至 80%；释义上下留白收紧；三个评分按钮宽度各为原来的 60%，整组居中；按钮到底部边界的距离为 1.4 倍。文字不整体缩放，揭示前后同高，长内容允许增高以免截断。
2. 设置首页各行视觉高度约为原来的 70%；平板触摸目标保留至少 44 CSS px，行内留白压缩，不挤压点击区域。
3. API Key 旁“不使用密钥”圆钮的轨道与圆点可见尺寸各缩至 70%，点击区域保持 44 × 44 CSS px；其他开关不随它缩小。
4. 移除“模型目录”标题，保留搜索、筛选和列表；默认模型、推理强度、测试连接、设为默认按此顺序同一行排列，后者位于测试右侧。

## R07 / R08 对实际工作的影响

- 数据库已有分析报告保存与读取，新分析追加记录；跳过新增“长期保存系统”和备份/换机/卸载恢复工作。
