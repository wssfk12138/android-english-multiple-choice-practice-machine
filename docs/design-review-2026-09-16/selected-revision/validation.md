## 实装后需另验

1. 原平板按钮 145/146 物理像素目标、四字标签、长标题及大字号不裁切，三按钮可点且不越卡片。
2. 复习卡片/评分按钮与底距按本轮比例；设置触摸目标至少 44 CSS px；复习长/短/空释义、长原句、异步更新无揭示跳动，旋转不丢词或重复评分。
3. 默认折叠与双列；长地址、键盘、多配置、0/1/2/多密钥、当前项在折叠部分、无密钥模式、错误均可操作。
4. 自动保存持久化、无效输入、连续编辑、重试、离页/旋转/重启；不误报成功、不用旧值覆盖新值、不泄露秘密。
5. 分析追加、完整历史查询、失败保留旧报告；保留错题跨离页、重启以及允许重新分析后仍可查看；删错题同时删关联分析、恢复/彻底清理同步，批量和多篇报告不误删；不测试换机或卸载恢复。
6. 分析完整正文、历史切换、生成失败、返回位置；查看与重新分析入口分开，浏览历史不触发模型请求。
7. 首页图标外布局、单词本学习页、题库、练习、导入和竖屏视觉均不回退。
8. 同条件性能前后比较，并验证后台任务与数据一致性。

最终检查仅针对文档链接、编码、预览功能及改动边界；不运行无关应用全量构建或测试。
