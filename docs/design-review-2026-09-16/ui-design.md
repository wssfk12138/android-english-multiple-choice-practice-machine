# UI 设计说明与覆盖范围

评审日期：2026-09-16。示例内容用于比较布局，不代表真实题库、学习进度、模型可用性或运行结果。推荐设计见 [决定清单](decisions.md)。本设计不授权应用改动。

## 统一设计

沿用英语刷题机的浅蓝主色、浅底与实体内容面板。主要操作用一个蓝色按钮，次要操作用普通按钮，危险操作保留文字含义和确认。标题下不再重复介绍标题。释义、原句和表单正文左对齐；复习卡上的单词可居中。

减少纵向空白主要通过合并重复标题、移动低频维护入口、缩短表单和统一内边距。保留可点击面积，长词、长地址、长出处和字体放大时允许换行增高。不要用固定高度、缩小字号或省略号隐藏必须阅读的内容。

预览中的侧栏与窄屏导航只用于在设计页面之间切换。全局导航、首页业务、题库规则和数据模型不由此获得重新设计授权。对没有明确结构问题的页面只整理标题、表单和操作排列；样例未展示的原有业务入口也不能在实施时删掉。

## 高频页面的具体结构

### 单词本与复习

宽屏的下半区按“列表 → 详情”阅读。两个面板顶边对齐，列表宽度有上下限；详情按单词、独立音标/词性、操作、释义、真题原句/出处、补充内容排列。遇见次数仍有位置，重点星标与学习状态不依赖颜色单独表达。

列表 B 是本轮推荐，尚未由用户选定。B 三组显示则已经由用户选定，两者不是同一个 B。没有把旧库里的空笔记认定为废弃功能。

窄屏保留当前行下展开详情的模式，不建立新的详情数据流。每日一背采用连续单栏作为推荐，长答案自然向下排，评分按钮位于答案之后；宽屏双栏只作为可选版式。

### API 页面

顺序：配置名/启用/默认状态及更多菜单 → 名称/协议/地址/请求地址 → 命名密钥管理 → 筛选模型/默认模型/推理强度/保存/测试 → 模型目录与可见筛选。

省略号菜单仍只有当前真实的“删除配置”，不凭空新增菜单动作。密钥保留选择、不使用密钥、添加、改名、删除；示例中的掩码不是实际密钥。请求地址仅在需要查看时展开。模型不支持强度时，禁用控件并保留简短原因。目录中不可用模型与“隐藏”状态是不同概念。

菜单必须处于不会被父卡片裁掉的层，靠近边界时调整位置，关闭菜单后焦点合理返回。单行工具栏以容得下内容为条件，不牺牲地址、模型名和错误提示可读性。

## 解释小字的删除边界

| 文字类型 / 原清单编号 | 处理 |
| --- | --- |
| S1 额外巩固标题解释、S2 外观主题解释、S11 更新普遍性说明 | 删除重复介绍；主题控件直接进设置首页 |
| N6 单词显示页解释页脚、N7 重复“默认显示”标签 | 删除；保留真实勾选与分组名称 |
| S3/S4 远程导入目标、S5/S6 文档导入目标相关提示 | 与真实覆盖/合并/新建结果有关的后果必须保留在目标附近或确认中，不能机械删除 |
| S7/S8 标注锁定说明 | 收敛成锁定状态，保留“已锁定项不覆盖”的必要后果 |
| S9 临时选择提示 | 仅在选择状态与保存结果确实容易混淆时出现 |
| S10 助手配置指导 | 已配置时不重复；未配置时给出可执行入口 |
| N1 遇见次数，N2 已开启数量 | 次数保留；已开启数量由 D06 决定是否显示在右侧 |
| N3 请求地址，N4 无模型指引，N5 强度不可用原因 | 地址按需展开，后两项在对应状态保留 |
| N8 释义、N9 校正后的语义、N10 单位 | 保留；它们是内容，不是标题注释 |
| 来源、错误、运行状态、隐私与删除后果 | 保留；以短而准确的文案呈现 |

## 响应式与单位

预览在 1205、1024、753、390、320 CSS px 宽度检查。侧栏约在内容宽 900 以下转为紧凑定位导航；单词双栏约在 700 以下改行下详情；窄表单约在 440 以下由同行改上下。这些是原型断点，不是将 Android 的 sw753dp 当作固定网页宽度。

实施时读取真实 WebView 的 innerWidth/innerHeight、devicePixelRatio、窗口内边距和键盘占用。CSS px、Android dp、截图像素的关系要由现场验证，不统一套一个倍数。字体放大时增加高度，不把桌面模拟字号作为系统字体缩放已经通过的证据。

## 如何比较

预览顶部切换 19 页；单词本顶部切换 A/B/C。每日一背、设置、API 的布局选择位于各预览页。宿主调整面板提供 D02 栏宽、D03 展开、D05 名称、D06 计数、D08 批量操作和 D10 宽松密度。它们是评审控件，不是计划新增到应用里的设置。

静态备选图见 [验证记录](validation.md)，便于宿主没有调整面板时比较。数据操作、网络和设备调用都是示意；表单输入不代表真实持久化。真实用户数据与应用安装完全不受预览影响。
