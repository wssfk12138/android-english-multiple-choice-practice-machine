# 导入题库页 UI 美化设计方案（2026-09-06）

状态：设计方案，未实施。实施时只动 `frontend/src/views/ImportView.vue` 模板与样式，不改任何业务函数（`performDocumentUpload`、`performEsqUpload`、发布/重试逻辑零改动）。

## 一、现状问题（基于 09-06 真机 1.35 字号截图）

1. **小字过多过长**：每个分区下都有常驻说明小字，1.35 字号下"试卷支持 DOC、DOCX；答案支持 DOC、DOCX、文本型 PDF。"折成 3 行，单是说明文字就占约一屏的 1/4；同类小字共 6 处以上。
2. **四个"选择文件"行视觉完全相同**：试卷/答案/听力音频/ESQ 四个选择器样式一致、纵向堆叠，扫读时无法快速区分"哪个是必填的主任务"。
3. **层级混乱**：页首"智能标注中心"胶囊按钮孤立悬浮，与配置选择器、两个导入任务、记录列表四种信息块平铺，没有主次。
4. **配置名裁切**：长 QA 配置名（如 QA-CET4-20260906）在下拉框内被截断为"QA-CET4-20"，无法确认当前目标（既有观察项）。
5. **冗余状态文案**："未选择任何文件""上传后会在这里保留草稿记录。"等常驻文案信息量低、占行高。

## 二、设计理念与不变项

- 理念：简洁、美观、方便用户查看信息；非必要小字一律删除，必要文字尽量短。
- 沿用现有风格：主题绿、卡片圆角背景、64px 行高、32px 图标列、统一入口宽度（不换肤，UI08 边界不动）。
- 保留全部功能与可达性：每个控件保留可访问名称；删除的常驻小字改为"交互时点提示"（出错或选中文件时按需出现），信息不丢失。

## 三、信息架构：三段式

```
① 页头：标题 + 配置行（全局目标，一眼可见）
② 任务区：两张等宽任务卡（文档导入 / ESQ 题库包），卡内统一"标签行+动作"模式
③ 记录区：导入记录列表（含智能标注中心入口收进此区头部）
```

## 四、ASCII 布局（竖屏 1240×2772，1.35 字号）

```
┌──────────────────────────────────────────┐
│ 导入题库                    ✦智能标注     │  ← 标题行 56px；智能标注降为图标+短文字入口
├──────────────────────────────────────────┤
│ ┌──────────────────────────────────────┐ │
│ │ 📖 QA-CET4-20260906              ▾  ⚙│ │  ← 配置选择器整行卡；长名横向滚动/自动缩字号；
│ └──────────────────────────────────────┘ │    ⚙=管理（图标，原"管理"文字并入可访问名）
├──────────────────────────────────────────┤
│ ┌ 📄 文档导入 ──────────────────────────┐ │
│ │ 试卷文件    [选择文件]      未选择     │ │  ← 统一 64px 行：标签 32px 图标列起
│ │ 答案文件    [选择文件]      未选择     │ │
│ │ 听力音频    [选择文件]      未选择     │ │
│ │ ☐ 允许模型修正题干和选项归属           │ │  ← 唯一保留的选项行，无小字
│ │ [        生成结构化草稿        ]       │ │  ← 主按钮全宽 56px
│ └────────────────────────────────────── ┘ │
│ ┌ 📦 ESQ 题库包 ────────────────────────┐ │
│ │ ESQ 文件    [选择文件]      未选择     │ │
│ │ [         校验题库包          ]        │ │
│ └────────────────────────────────────── ┘ │
├──────────────────────────────────────────┤
│ 导入记录                                  │
│  ● cet4-complete-v1.2.0.esq    已发布    │  ← 状态用色点+徽标，不用整行小字说明
│  ○ postgraduate-….esq          草稿      │
│  …                                       │
└──────────────────────────────────────────┘
```

行规格：每个文件行 = 32px 图标列 + 标签（试卷文件/答案文件/听力音频/ESQ 文件）+ 右对齐主按钮"选择文件" + 状态文字（已选文件名截断显示，点击可预览）。选中文件后状态文字替换为文件名（绿色），与"未选择"灰色形成对比。

## 五、小字处置清单（删除/改造）

| 现文案 | 处置 | 理由 |
| --- | --- | --- |
| 试卷支持 DOC、DOCX；答案支持 DOC、DOCX、文本型 PDF。 | 删常驻 | 文件选择器 accept 已过滤；格式不符在选文件时即时报错 |
| 听力音频（可多选，支持 MP3 / M4A / WAV / OGG） | 改"听力音频" | 多选与格式由选择器承担 |
| 上传时使用模型辅助定位题目与答案（checkbox 主文案） | 保留 | 功能开关，必要 |
| 默认全量核对；失败时保留本地草稿。 | 删 | 行为默认正确；失败有结果反馈 |
| 允许模型修正题干和选项归属（checkbox 主文案） | 保留 | 功能开关，必要 |
| 默认关闭，仅在材料能明确证明错位时修改。 | 删 | 主文案已表意 |
| 生成结构化草稿 | 保留 | 主按钮 |
| 扫描版或水印严重且没有文字层的答案 PDF 会提示人工录入。 | 改条件提示 | 仅当选中的 PDF 无文字层时显示行内提示条 |
| 保留跨设备分享与远程题库更新能力。 | 删 | 无操作含义 |
| 未选择任何文件 | 改"未选择" | 短状态词 |
| 上传后会在这里保留草稿记录。 | 删 | "导入记录"标题自明 |
| 底部固定条提示（选择导入记录开始校对 / 逐字段编辑能直观看到文章、题干、选项与归属） | 删 | 选中记录后自然进入校对界面 |
| 智能标注中心胶囊按钮 | 改标题行右侧图标入口"✦智能标注" | 消除孤立悬浮块，腾出首屏 |

条件提示（保留能力、按时点出现）：
- 选中无文字层 PDF → 行内提示条："该 PDF 无文字层，请人工录入答案。"
- 选中的文件类型不符 → 行内提示条："试卷支持 DOC、DOCX。"（或对应类型）
- 模型辅助失败 → 既有失败提示保留（失败不破坏草稿）。

## 六、记录列表细节

- 状态徽标：已发布（绿点）/ 草稿（灰点）/ 已移入回收站（红点），右侧对齐；替代纯文字长说明。
- 文件名超长：中段省略（保留扩展名），完整名放 content-desc。
- 每行高度 64px，点击整行打开预览（现有行为不变）。

## 七、验收与实施路径

1. 实施：仅 ImportView.vue 模板/样式；新增条件提示所需的两个现有状态位复用（不新增业务状态）。
2. 自动验收：`test:android-public-ui` 契约更新 + 前端生产构建 + `git diff --check`。
3. 真机验收：竖屏 1.35 字号截图对比（页首/任务卡/记录区三屏）；选择文件→校验→打开记录→无损关闭全操作；深色模式过一遍；确认删除的小字信息在对应交互时点仍可达。
4. 明确不做：不改 ESQ/文档解析逻辑、不改发布流程、不动其他页面（本方案只覆盖导入页）。
