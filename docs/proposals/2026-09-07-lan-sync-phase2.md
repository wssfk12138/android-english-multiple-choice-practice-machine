# LAN 同步二期执行计划

用户已批准按下列产品边界在四个独立本地工作树实施。源码同步不等于 GitHub 推送、Release 或设备安装授权；最终真机和视觉验收交用户。工作树绝对路径见 MAP.md。

## 已确定的产品契约

- 同步选项：做题记录、模型配置（包含 API Key）、题库、单词本、错题本。按设备选择；服务端强制执行有效权限，不能只隐藏客户端控件。
- 模型支持命名多密钥与手动选用，不自动轮换。按 baseURL 识别配置，去首尾空白和规范主机名大小写，不合并不同协议、路径、路径大小写或 /v1。相同 URL 保留接收方配置名称、协议、选项和当前密钥，只追加不同密钥；相同密钥不重复加入。认证方式不兼容时暂停该配置并显示明确原因。
- 模型删除不跨端传播；接收方主动删除的密钥需要本地抑制记录，避免下一次自动同步复活。密钥不得进入 SQLite 明文、日志、二维码、错误信息或公开文档。
- 题库仅 Windows 向 Android 分发。Windows 公测版独立控制开放和共享范围，使用隔离共享区，不暴露私人数据目录。新题库仅列入可选列表，用户选中后下载。相同包/内容默认不重复导入；更新与分叉冲突走现有预览流程，保留学习引用。
- 首次绑定后无需重新配置题库来源，电脑地址变化可自动恢复；恢复必须认证原电脑身份。官方 GitHub 题库源、LAN 题库源、应用更新源彼此独立。
- 绑定凭证才是认证依据，设备名称或公开标识不能作为凭据。旧安装重新扫码复用原设备；重装丢失身份后明确选择替换旧绑定，不根据名称或 IP 猜测合并。支持逐设备撤销。
- UI 紧凑、信息集中，无非必要标题下小字；按钮优先图标并配 accessible label/tooltip；电脑二维码有固定框；安卓取景前台可见，横竖屏不挤压操作区。四端晨光/暮色背景与暗色石墨灰主题统一。

## 阶段和顺序

### S1 扫码可见性与生命周期

状态：双安卓源码、单元测试、生产构建、Capacitor 同步和 Debug APK 编译通过；未安装，真机待用户。

复用现有 Capacitor ML Kit 8.1.0。按照官方 behind-WebView 模式提供 Teleport 前台透明取景层；关闭、返回、后台、页面卸载和失败均释放相机与自有监听器；会话锁覆盖闪光灯清理，避免旧会话影响新会话。不修改数据库与 ESQ。

来源：https://github.com/capawesome-team/capacitor-mlkit/tree/main/packages/barcode-scanning#usage

### S2 身份、认证传输和恢复

状态：开发完成（S2a-S2d，2026-09-07），不等于部署及真机全链路验收完成。四树已接入持久身份、独立 TLS 监听、180 秒单次扫码邀请、安全凭据、逐设备撤销、显式重装替换和 mDNS/NSD 认证后自动换址。定向测试、四端构建、双 Android 原生测试/Debug 编译、隔离冻结 TLS 冒烟和二维码图像解码通过；实际相机、Android NSD/路由器组播、SecureStore 重启及完整 Windows 发行包仍待部署验收。8767/5353 防火墙脚本已提供但未执行。本窗口按用户要求结束于 S2，不进入 S3-S6。证据与限制见 [2026-09 历史](../context/history/2026-09.md)。

S2d 兼容契约：新 Windows 二维码采用 EPM2 紧凑载荷，仍携带完整公开证书；需配套新版 Android 扫码器，不能假定旧发行 APK 支持。新版 Android 继续接受旧 v1/v2 JSON。发现结果只提供候选地址，不提供信任；必须通过原固定身份认证并成功保存安全凭据后才更新地址。重装替换目标由电脑端明确选择，数据库事务成功前保留旧绑定、会话和邀请。API Key 在 HTTP/TLS 均继续禁止同步，留 S3/S4。

S2b 兼容契约：旧 HTTP 行为保持且不传密钥；显式传入可信 v2 身份时，只允许 HTTPS、固定证书和身份匹配，失败不回退 HTTP。证书信任必须来自带外确认，不得从未认证 HTTP 自动采信。持久身份损坏/过期/DPAPI 失效时禁止自动重建，后续需明确恢复或重配流程。当前没有自动升级旧绑定。

接口参数约束复用现有 FastAPI 0.116.1 的 Path/Query 校验，无新增依赖。来源：https://github.com/fastapi/fastapi/blob/0.116.1/docs/en/docs/tutorial/path-params.md

1. 先检查四端握手、凭证存储、原生 HTTP、启动/服务配置和相关测试，形成新增协议能力与旧版本兼容表。
2. 选择成熟 TLS/证书固定与系统安全存储实现，验证 Python、Windows 打包、Android OkHttp 和旧版兼容性；不自研密码协议。二维码携带身份和短期配对材料，不携带模型密钥。未认证或旧协议连接不得传密钥。
3. 持久宿主身份、安装身份、认证迁移、设备列表、单设备撤销、重装替换确认；撤销同时失效活动会话。
4. 基于成熟 mDNS/Android NSD 发现地址，重新连接前校验宿主身份；不因同名电脑或 IP 重用发送凭证。
5. 隔离数据库测试：同设备反复绑定、伪造 ID、撤销后旧会话、主机地址改变、证书变化、旧客户端、重装替换与连接中断。

### S3 五类同步权限和游标

状态：开发完成（2026-09-07），四个权威源码树已定向同步；部署、真机及完整矩阵验收后置。本任务止于 S3，不进入 S4-S6。

定义类别与数据表/依赖图，做题记录和错题本独立选取时必须保留所需题目引用。双端同意的权限交集在服务端检查；类别与方向独立游标，重新开启类别可补齐缺失历史。拒绝未知类别和越权数据；不推进失败批次游标。四端实现一致选项和状态界面，删除标题下非必要说明。

S3 契约：practice=会话/作答/事件/篇目提交；models=模型配置（不含任何密钥）；vocabulary=词条/出处/复习；wrong=错题统计/轮次/轮次题目/当前池；question_bank 仅保留 Windows 到 Android 权限，内容分发仍待 S5。默认四类学习数据开启、题库关闭。Windows 按设备保存许可，Android 按主机保存选择，握手交集绑定会话，每次 pull/push 重新检查当前许可；旧客户端在受限权限下拒绝整集同步，新客户端连接不支持分类的主机时拒绝继续。

每个主机、类别独立保存 remote/local 与各自 tombstone 游标，四个游标在该类别 push 成功后一次写入。关闭类别不清游标，重开接续；profile 指纹变化重放该类别，旧全局游标不复用。错题先处理，单类别失败保留其游标，其他类别仍可完成，但整次不报告成功。错题独立同步只携带被本批轮次引用的最小会话依赖；固定最早时间戳 0001-01-01T00:00:00Z 防止迁移回填为最新，占位不进入做题导出且不能覆盖已有完整会话。真实记录可后续补全。缺少题库稳定引用整批回滚；做题会话删除若会级联影响仍存在的错题轮次则拒绝，保留数据等待两端处理。ESQ 格式不变。

验证：Windows 本地 37/公开 39 项定向 unittest；Android 本地 9/公开 11 组定向脚本；四前端生产构建通过。包括真实内存 SQLite 依赖、重放、回滚、游标关闭重开、权限撤销、越权和密钥拒收。未做真机/安装/原生构建/视觉矩阵或真实服务重启；详见月度历史。

### S4 命名多密钥与增量合并

状态：开发完成（2026-09-07），四权威源码树已定向同步；止于 S4，S5/S6 未开始。真机与最终视觉验收后置。

旧单密钥迁为默认命名条目并保留选中项；Windows 使用独立 DPAPI sidecar，Android 使用 Keystore 加密 SecureStore，先持久保存再清旧值。支持增加、改名、删除、手动选择和不选用，不自动轮换；新接收配置不自动选中密钥。URL 去首尾空白、规范 scheme/host，保留显式端口、路径大小写、尾斜杠和 /v1。相同 URL 保留本机名称、协议、选项与选中项，只追加未知密钥；冲突按配置 ID 明确提示。模型和密钥删除不跨端传播，本地抑制防止复活。

S4 取代上文 S2/S3 当时的模型传输限制：模型类别仅走独立 /model-keys 端点，要求双方 model_keys_version=1、固定 TLS 身份及 S3 models 权限；HTTP 和普通学习快照仍不含密钥。按密钥身份清单增量交换并允许幂等重放，不沿用普通表模型游标。旧普通模型输入与墓碑不再合并，显式旧 models 请求拒绝；其他学习类别保持兼容。ESQ 格式不变。

验证：Windows 本地 44/公开 46 项定向 unittest；双 Android model-keys、lan-categories、lan-category-dependencies 通过；LAN 脚本本地 9/公开 10 组通过。四前端生产构建通过，最终 Android 事务修正后补跑双端 vue-tsc；双 Android Java 编译和公开树原生单元测试通过（传输类 3 项，含 HTTP/无固定身份拒绝）。使用合成密钥和隔离存储，没有读取真实配置或调用真实供应商。

交付限制：OpenCodex 布局逐项对照、实际 UI/字体缩放、SecureStore 真机进程重启/磁盘故障、实际 Wi-Fi 多端及冻结发行包验收未执行，不能以编译/模拟重启代替。安全存储失败采用停止操作保护，损坏存储恢复和抑制记录长期增长仍需后续专项；未安装、重启真实应用、改版本、提交或发布。详见月度历史。

### S5 Windows 题库共享与 Android 订阅

当前契约：隔离 SHA 地址化 ESQ 与原子目录，固定 TLS/v2 question_bank 权限，下载逐块复核撤销；Android 显式目标、原生流式完整性校验后进入现有预览，不自动批准。残余：导出器完整内存包、旧 blob 留存和逐块数据库连接开销需专项；更新默认要求选择已有配置。S5 仍需原生下载哈希/截断和生产更新/分叉引用的补充验证。
