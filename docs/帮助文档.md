# 英语刷题机使用帮助

> 适用版本：`0.1.0-alpha` 内测版（具体版本号以应用内「更新与远程题库」页面显示为准）

## ⚠️ 使用前必读：先配置好模型

英语刷题机的多项核心功能依赖大模型（AI）提供能力：

- AI 学习助手对话
- 错题本 AI 错因分析
- 单词本单词翻译与辨析
- 题库导入时的「模型辅助定位题目与答案」
- 题库智能标注（考点、干扰项类型等）

**未配置模型之前，以上功能不可用，或会提示“请先配置并启用一个模型”。**

首次使用前，请先完成以下三步：

1. 在 DeepSeek 官网注册账号并创建 API Key（见第二部分）；
2. 在应用「模型与 API」页面新建一条 API 配置并粘贴密钥（见第三部分）；
3. 同步模型、选择默认模型、测试连接成功（见第三部分）。

配置一次即可，之后所有 AI 功能共用这套配置。

## 一、什么是 API 与 API Key？

- **API（应用程序编程接口）**：可以理解为“服务商提供的标准化服务入口”。对英语刷题机来说，DeepSeek 把它的 AI 模型能力封装成 API——刷题机向 DeepSeek 服务器发送请求（例如“翻译这个单词”“分析这道错题”），服务器调用模型处理后返回结果。
- **API Key（密钥）**：相当于你访问这项服务的“通行证 / 账号密码”，是一串随机字符，用来：
  - 证明你的身份；
  - 对使用量计费；
  - 防止别人盗用你的额度。
- 刷题机**不会内置任何人的密钥**。你需要用自己的 DeepSeek 账号生成一个 Key，粘贴进应用，由应用**本地加密保存**。
- **费用**：DeepSeek API 按实际 token 消耗量计费（先充值后用），费用 = token 消耗量 × 模型单价，从充值余额或赠送余额中扣减（优先扣赠送余额）。不同模型价格不同，具体以官方「模型与价格」页（`https://api-docs.deepseek.com/zh-cn/quick_start/pricing`）为准；官方提示近期将整体上调价格，请以官网最新价格为准。

## 二、如何在 DeepSeek 官网获取 API 与 API Key

以下流程以 DeepSeek 官方开放平台与官方文档为准（文档：`https://api-docs.deepseek.com/zh-cn/`）。

1. **注册 / 登录开放平台**：用浏览器打开 `https://platform.deepseek.com`，使用手机号或邮箱注册账号并登录（平台也支持 Google / 邮箱等登录方式，以登录页显示为准）。
2. **进入「API Keys」页面**：登录后进入控制台，点击左侧菜单的「API Keys」（或直接访问 `https://platform.deepseek.com/api_keys`）。官方文档申请 API Key 的入口也指向该页面。
3. **创建 API Key**：点击「创建 API Key」，按页面提示填写名称（方便区分用途）后确认创建。
4. **立即复制保存**：创建完成后，页面会**完整显示一次**密钥，请立即复制并妥善保存（建议存入密码管理器）。关闭页面后**无法再查看完整密钥**；忘记或丢失只能删除后重新创建。
5. **充值**：DeepSeek API 按量计费，需要账户有余额才能调用。完成**实名认证**后，在「充值」页面（`https://platform.deepseek.com/top_up`）使用**支付宝或微信**在线充值；充值余额**永久有效，不会过期**。账户可能同时存在充值余额与赠送余额，扣费时优先扣减赠送余额；可随时在「交易记录」页面（`/transactions`）查询充值结果。
6. **记下两个信息**（第三部分要用）：
   - **Base URL（接口地址）**：`https://api.deepseek.com`；
   - **可用模型名**：官方当前提供 `deepseek-v4-flash`（DeepSeek-V4-Flash-0731，性价比高）与 `deepseek-v4-pro`（能力更强）两个模型，具体以官方「模型与价格」页为准。

**安全提醒**：API Key 等同密码，不要截图发到群里、不要写进聊天记录。若怀疑泄露，请立即到「API Keys」页面删除该 Key（页面提示“API Key 已删除”即表示已立即失效），删除后重新创建并替换到应用中；也可在「用量」页面（`/usage`）按时间与 API Key 查看各密钥的使用情况。在刷题机中，密钥只保存在本机加密存储里，不会进入数据库、日志，也不会被上传。

## 三、如何在英语刷题机中配置模型并使用

### 3.1 打开「模型与 API」

在应用内打开「设置」→「模型与 API」页面（手机竖屏下通过底部导航进入设置）。

该页面像工作区一样管理多个接口配置：可以新建多条 API 配置（例如同时保留 DeepSeek 和其他兼容接口）。**只有“启用”的 API 和“可见”的模型会出现在 AI 助手的模型选择器里。**

### 3.2 新建 / 编辑一条 API 配置

点击「新建 API 配置」，按以下字段填写（以 DeepSeek 为例）：

| 字段 | 填写内容 |
| --- | --- |
| 配置名称 | 任意名称，例如“DeepSeek” |
| API Base URL | `https://api.deepseek.com`（应用会自动拼接 `/chat/completions` 与 `/models`） |
| API Key | 粘贴第二部分创建的密钥；密码框显示，保存后加密存本机，再次进入显示为“密钥已加密保存在本机” |
| 默认模型 | 可先留空，保存后点「同步模型」再选择；DeepSeek 可填 `deepseek-v4-flash`（推荐，性价比高）或 `deepseek-v4-pro` |
| Temperature | 回答随机性与创造性（0–2）。判分、错题分析、导入、翻译等任务建议 0.2–0.5（默认 0.2） |
| 输出 Token 上限 | 当前版本已停用（保留旧配置兼容），输出长度由模型供应商决定 |
| 附加系统提示词 | 可选，对该配置下所有模型统一生效的额外要求 |

说明：

- 应用默认的 Base URL 占位是 `http://127.0.0.1:11434/v1`（本机 Ollama 地址）。**在 Android 手机上该地址指向手机本身，不能直接使用**；用 DeepSeek 请改为 `https://api.deepseek.com`。
- 多套配置时，可用「设为默认」指定默认配置；「启用」开关控制该配置是否参与 AI 功能；「删除」可移除配置（至少保留一条）。

### 3.3 同步模型并选择默认模型

1. 保存配置后，点击「**同步模型**」。应用会请求该接口的模型列表（OpenAI 兼容的 `/models`），把账号下可用的模型拉取进来。
2. 在「默认模型」下拉框中选择要使用的模型（DeepSeek 推荐 `deepseek-v4-flash`，需要更强推理能力可选 `deepseek-v4-pro`）。
3. 在「模型选择器」中可单独控制每个模型是否“显示”——隐藏后仍保留在配置中，但不会出现在 AI 助手切换菜单里（也可「全部显示 / 全部隐藏」）。

### 3.4 测试连接

选择好默认模型后，点击「**测试连接**」。应用会发送一句“只回复‘连接成功’”的请求；返回“连接成功”即配置正确。常见失败原因：

- API Key 错误或已失效 → 到平台重新创建并粘贴；
- 账户余额不足或未充值 → 完成实名认证后，在平台「充值」页（`https://platform.deepseek.com/top_up`）用支付宝 / 微信充值；
- 网络不通（公司 / 校园网、代理等）→ 检查网络；
- Base URL 填错 → 对照官方地址检查。

### 3.5 配置好后如何使用 AI 功能

- **AI 学习助手**：从首页或导航进入「AI 学习助手」，在发送框旁选择模型后直接提问（例如语法讲解、长难句分析、复习建议）。应用内置提示词约束助手“除非用户明确要求，不主动泄露标准答案”。
- **单词翻译**：做题时点选或长按生词加入单词本；**退出答题界面后**自动进入翻译队列。翻译完成后可查看音标、词性、语境义、常用义、记忆提示、同义词 / 反义词 / 形近词辨析。
- **错题 AI 分析**：在「错题本」中选择范围（某篇 / 某年 / 全部）后点击「分析」。分析过程匿名化，不会复述题干、选项或答案字母；结果缓存在本地，完成该篇下一次练习后才可重新分析并对比两次作答。
- **题库导入辅助**：导入 Word / PDF 时勾选「用模型辅助定位题目与答案」，模型帮助把题目与答案对应起来，生成逐字段草稿供你校对。
- **题库智能标注**：在「导入题库」页的智能标注中心，选择范围（全部题库 / 按年份 / 本次导入），开始标注后模型按整篇材料为每道题生成考点、次要技能、干扰项类型、注意事项等标签；可后台继续、当前篇后暂停、随时查看并人工校正。标签会复用于错题分析，减少重复输出。

## 四、英语刷题机目前有哪些功能

### 1. 刷题练习

- 支持完形填空、阅读理解、Part B（多项选择）等客观题题型；
- 三种练习入口：**按年份练习**、**随机抽取整篇**、**听力单刷**（完成一套试卷的完整听力部分）；
- 选项打乱，降低“背答案”影响；
- 答案自动保存；支持单篇提交与整卷提交；未答完时阻止提交并自动定位到未答题目。

### 2. 听力练习

- 导入试卷时可为试卷选择听力音频（支持多段音频、多套选择与单套导入确认）；
- 听力页不显示原文，跟随完整音频答题；可切换音频曲目；
- 计时模式下播放进度锁定（不能快进、后退或拖动），音频正常连续播放；非计时模式可拖动进度。

### 3. 错题本

- 按年份与篇目整理错题；错题统计、高频错题标记；
- AI 匿名错因分析（不泄露答案），结果本地缓存，重做后可重新分析并对比两次错误选项；
- 一键错题重做。

### 4. 单词本

- 做题中遇到的生词一键加入；退出答题界面后自动后台翻译；
- 词条包含音标、词性、语境义、常用义、记忆提示、同义词 / 反义词 / 形近词辨析；
- 今日复习（按复习调度）、高频生词、学习中 / 已掌握等状态管理；各板块显示可配置。

### 5. AI 学习助手

- 多套 API 配置、模型切换、对话历史管理（本地保存最近对话）；
- 可自定义附加系统提示词；默认不主动泄露标准答案。

### 6. 题库导入（Word / PDF / ESQ）

- 试卷支持 **DOC、DOCX**；答案支持 **DOC、DOCX、文本型 PDF**；
- 流程：模型辅助定位题目与答案 → 逐字段草稿校对（文章、题干、选项、标准答案、答案来源、Part B 候选）→ 批准入库；
- 一次只导入一套试卷；同一文件含多套时仅导入第 1 套并明确提示；
- 扫描版或水印严重、没有可靠文字层的 PDF 会明确提示人工处理，不会把 OCR 失败伪装成成功导入；
- ESQ 题库包（1.0 / 1.1）导入：目录检查、预览、校验、冲突处理（使用导入版替换或保留本地）；
- 远程题库：目录检查 → 下载 → 文件大小与 SHA-256 校验 → 导入预览 → 确认后导入；不会自动覆盖已有年份。

### 7. 题库智能标注

- 模型为每道题生成考点、次要技能、干扰项类型、注意事项、词汇 / 上下文 / 语法依赖等标签；
- 支持三种范围：**全部题库、按年份、本次导入**；
- 后台继续、当前篇后暂停、进度显示、按年份 / 篇目 / 题号 / 考点搜索与人工校正。

### 8. 更新与远程题库

- 程序更新与题库更新相互独立；
- 程序更新：检查更新清单 → 下载 APK → SHA-256 校验 → 打开 Android 系统安装器由你确认安装（不会静默安装），安装后可选择保留或删除安装包；
- 更新源可配置（正式版建议 GitHub Releases 的 HTTPS 清单；内测可使用局域网地址）。

### 9. 数据与隐私

- 题库、练习记录、错题、单词本、AI 对话与配置全部保存在应用本地（SQLite）；
- API Key 通过 Android 系统安全存储（Keystore + AES/GCM）加密保存，不进入数据库、日志或源码；
- 应用关闭 Android 系统备份，密钥密文与学习数据不会进入云备份；
- ESQ 题库包不包含个人练习记录、错题、单词本、对话或 API 配置；
- 只有你主动提交的内容（聊天、错题分析、待翻译单词）会被发送给远程模型。

### 10. 界面适配

- 平板大屏双栏布局、中等窗口导航轨道、紧凑窗口单栏布局；
- 手机竖屏适配：底部导航、答题卡、文章 / 题目切换、听力音频 / 题目切换；
- 竖屏 Ink & Amber 主题（方案 B）。

## 常见问题（FAQ）

- **点了 AI 功能提示“请先配置并启用一个模型”？** → 按第三部分完成配置，并确认该配置的「启用」开关已打开。
- **测试连接失败？** → 见 3.4 节常见失败原因。
- **单词一直没有翻译？** → 退出答题界面后才会启动翻译队列；可在单词本「等待翻译」中查看状态并重试；确认模型配置可用。
- **错题分析显示“本地缓存”？** → 完成该篇错题的下一次练习后，才允许重新分析并对比。
- **导入扫描版 PDF 失败？** → 该类文件没有可靠文字层，应用会提示人工处理；可先在 Windows 电脑版完成导入与人工校正，再导出为 ESQ 供 Android 导入。

## 五、我不会编程，如何按我的想法修改这个程序？

### 5.1 先理解：AI 开发工具是怎么帮你改程序的

现在的 AI 开发工具（也叫“AI 编程助手 / 编程智能体”）能够读懂整个项目的代码，按你的中文描述直接修改文件，并替你执行构建、测试等命令。你不会编程也能用，但需要做好三件事：

1. **把想法说清楚**：描述你要改什么、改成什么样、怎么算成功；
2. **让 AI 先讲方案再动手**：避免方向错了白改一遍；
3. **每次改动后验证结果**：构建 + 装到手机上实际试一下。

### 5.2 推荐流程（非程序员版）

1. **写需求**：用一两句话描述你想改什么，例如“把答题页的选项字放大”“在首页加一个总正确率”。
2. **备份**：把项目文件夹复制一份，或先用 git 提交一次（可以让 AI 工具代劳）。
3. **交给工具**：在工具中打开本项目文件夹，把需求发给它，并要求它**先解释打算怎么改、会影响哪些文件**。
4. **确认方案**：看不懂没关系，追问“这样改会破坏现有功能吗？需要改哪些地方？”
5. **动手修改**：让它修改代码并执行构建验证（本项目的固定命令见下）。
6. **安装测试**：把生成的 APK 装到手机上，按你的需求逐项试用。
7. **不满意就回滚**：让 AI 撤销本次改动，或恢复备份，换个思路再来。

本项目的标准验证命令（可直接让 AI 工具执行）：

```text
corepack.cmd pnpm run build
corepack.cmd pnpm exec cap sync android
frontend\android\gradlew.bat assembleDebug
```

### 5.4 以 DeepSeek 为例：把 DeepSeek 接入这些 AI 开发工具（新手详细教程）

为什么要接入：很多工具的模型是订阅制；DeepSeek API 按量付费（见第二部分），而且官方提供了接入教程，可以作为这些工具的“省钱模型”。下面的教程比官方文档更细，专门写给不太熟悉电脑操作的用户。

#### 5.4.1 新手先认识三个名词

- **命令行 / 终端**：Windows 上一个可以输入文字命令的黑色窗口，叫“命令提示符”或“PowerShell”。打开方法：按键盘上的 Windows 徽标键，输入 `powershell`，回车。本教程里的“在终端执行 xxx”，就是指在这个窗口输入 xxx 后按回车。
- **配置文件**：程序用来记录设置的文本文件，用系统自带的“记事本”就能打开和修改。
- **环境变量**：给程序预设的“全局参数”。程序启动时会读取它。本教程用到的环境变量，本质是告诉 Claude Code：“模型的接口地址用 DeepSeek 的、鉴权密钥用我的 DeepSeek API Key”。

#### 5.4.2 准备工作（做一次，所有工具通用）

1. 按第二部分完成：注册 → 实名认证 → 充值 → 创建 API Key（以 `sk-` 开头）；
2. 把 API Key 复制到记事本里临时放着（本教程中所有 `<你的 DeepSeek API Key>` 都要替换成你自己的密钥，注意不要带多余的空格）；
3. 确认电脑能正常上网。

#### 5.4.3 官方文档地图

DeepSeek 官方“接入 Agent 工具”文档：`https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/`，目前收录了 **Claude Code、Codex、OpenCode、OpenClaw、Hermes、Reasonix、WorkBuddy/CodeBuddy** 的接入教程。每一篇都是“跟着做就能成功”的教程，且会随工具版本更新，动手前先打开对应页面核对。

全文档通用的两个信息：

- OpenAI 格式 Base URL：`https://api.deepseek.com`
- Anthropic 格式 Base URL：`https://api.deepseek.com/anthropic`
- 可用模型：`deepseek-v4-flash`、`deepseek-v4-pro`

#### 5.4.4 教程一：Codex 接入 DeepSeek（推荐新手）

先说明三点：

- 官方提示：目前**仅 `deepseek-v4-flash` 支持接入 Codex**，`deepseek-v4-pro` 预计 2026 年 8 月初支持（以官方文档为准）；
- Codex 的三种形态——**Codex CLI（命令行）、ChatGPT 桌面端、VS Code 的 Codex 插件**——共用同一份配置文件，**配置一次，三处都能用 DeepSeek**；
- 官方提供“一键配置脚本”，会帮你自动备份、写文件和校验，**新手首选**。

**方法 A：一键配置脚本（推荐）**

1. 按 Windows 徽标键，输入 `powershell`，回车，打开 PowerShell 窗口；
2. 复制下面这一整行命令，在窗口里右键粘贴，按回车执行：

   ```text
   irm https://cdn.deepseek.com/api-docs/codex-deepseek-setup-en.ps1 | iex
   ```

3. 按脚本菜单提示选择要使用的模型（`deepseek-v4-flash`）；
4. 首次运行会提示输入 API Key，粘贴你的密钥（`sk-` 开头）后回车；
5. 脚本会自动完成：把原配置备份到 `~/.codex/backup-deepseek/`、写入模型元数据文件 `~/.codex/models.json`、修改 `~/.codex/config.toml` 并校验语法——**校验失败时不会改动任何文件**；
6. 之后想切换模型或恢复安装前的默认配置，重新运行同一行命令，选菜单第 3 项即可。

新手提示：

- 脚本要求电脑上**已经装过 Codex 并运行过至少一次**（即 `~/.codex` 目录已存在）。如果提示找不到目录，先打开一次 Codex 再执行脚本；
- PowerShell 里粘贴命令是按**右键**（不是 Ctrl+V），如果粘贴后没有反应，检查是否复制完整。

**方法 B：手动编辑配置文件（想了解原理时再看）**

1. 找到配置文件：在文件资源管理器地址栏输入 `%USERPROFILE%\.codex` 回车，找到 `config.toml`；右键用“记事本”打开（没有就新建一个空文件）；
2. 在文件末尾添加下面的内容（`<你的 DeepSeek API Key>` 换成你自己的密钥）：

   ```toml
   model_provider = "deepseek"

   [model_providers.deepseek]
   name = "DeepSeek"
   base_url = "https://api.deepseek.com/"
   wire_api = "responses"
   experimental_bearer_token = "<你的 DeepSeek API Key>"
   ```

3. 记事本里点“文件 → 保存”（编码保持 UTF-8）；
4. 还需要一个 `models.json` 文件，向 Codex 声明 DeepSeek 模型的上下文长度等元数据，内容较长，请从官方文档「接入 Codex」页面原样复制（脚本写入的就是这份内容，手动方式下不要抄漏）；
5. 重启 Codex。

**验证是否成功**：重启 Codex 后，直接问它“你现在使用的是什么模型？”，或在模型菜单中选择，能看到 `deepseek-v4-flash` 即成功。

**常见问题**：

| 现象 | 原因与处理 |
| --- | --- |
| 找不到 `~/.codex` 目录 | 先打开一次 Codex 再执行脚本 |
| 脚本执行报错 / 没有反应 | 检查是否复制完整；或改用方法 B 手动配置 |
| 提示 401 认证失败 | API Key 复制错误或带空格，重新复制后重试 |
| 选 `deepseek-v4-pro` 报错 | 官方提示该模型预计 2026 年 8 月初才支持接入 Codex，先用 `deepseek-v4-flash` |

#### 5.4.5 教程二：OpenCode 接入 DeepSeek（开源，终端 + 网页）

OpenCode 是开源 AI 编程助手，提供终端和网页两种形式，DeepSeek 官方给出如下步骤：

1. **安装**：打开 `https://opencode.ai/zh/download`，下载 Windows 版本并安装；
2. **升级到最新版**：打开终端，执行 `opencode upgrade`（要求版本 >= v1.14.24，避免兼容问题）；
3. **启动**：终端执行 `opencode`；
4. 在输入框中输入 `/connect` 并回车，然后输入 `deepseek`，在列出的供应商中选择 DeepSeek；
5. 粘贴你的 DeepSeek API Key；
6. 选择 `DeepSeek-V4-Pro`（或 `deepseek-v4-flash`）模型。

新手提示：终端里输入命令后按回车执行；`/connect` 是在 OpenCode 的输入框里输入的斜杠命令，不是 Windows 命令。装好后随便问一句（例如“用中文介绍一下你自己”），能正常回答即成功。

#### 5.4.6 教程三：Claude Code 接入 DeepSeek（终端）

**第一步：安装 Claude Code**（如果已经装过，直接看第二步）

1. 安装 Node.js 18 或更高版本：打开 `https://nodejs.org`，下载 LTS 版，一路“下一步”安装；
2. Windows 用户还需安装 Git for Windows：打开 `https://git-scm.com` 下载安装；
3. 打开终端（PowerShell），执行安装命令：

   ```text
   npm install -g @anthropic-ai/claude-code
   ```

4. 验证是否成功：执行 `claude --version`，能看到版本号就说明装好了。

**第二步：设置环境变量（Windows 在 PowerShell 中执行）**

把下面每一行依次粘贴到 PowerShell 窗口执行（`<你的 DeepSeek API Key>` 换成你自己的密钥）：

```powershell
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="<你的 DeepSeek API Key>"
$env:ANTHROPIC_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_OPUS_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_SONNET_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_SUBAGENT_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_EFFORT_LEVEL="max"
```

每一条的含义（看一两条就够了）：

- `ANTHROPIC_BASE_URL`：把 Claude Code 的接口地址指到 DeepSeek（Anthropic 兼容格式）；
- `ANTHROPIC_AUTH_TOKEN`：填你的 DeepSeek API Key，用它鉴权；
- `ANTHROPIC_MODEL` 及三个 DEFAULT 模型：决定默认用哪个 DeepSeek 模型（`deepseek-v4-pro` 能力更强，`deepseek-v4-flash` 更快更省）；
- `CLAUDE_CODE_EFFORT_LEVEL`：推理强度，`max` 表示尽力思考。

新手提示：这些 `$env:` 命令**只在当前 PowerShell 窗口有效**，关掉窗口后下次要重新执行一遍；想永久生效，可以在“系统属性 → 环境变量”里手动添加同名变量（内容一样）。

**第三步：进入项目目录并启动**

```text
cd 你的项目路径
claude
```

**官方补充说明**：

- Claude Code 里的模型名会被自动映射：`claude-opus` 开头的模型 → `deepseek-v4-pro`；`claude-haiku` / `claude-sonnet` 开头的模型 → `deepseek-v4-flash`；
- Claude Code 的 Web Search 功能 DeepSeek 原生支持，但搜索结果的总结会额外产生模型 Token 费用。

#### 5.4.7 三个教程都失败时：通用检查清单

| 检查项 | 怎么做 |
| --- | --- |
| API Key 是否正确 | 以 `sk-` 开头，复制完整、无多余空格；平台页面可重新创建 |
| 账户是否有余额 | 到 DeepSeek 平台「用量」页面查看；余额不足需充值 |
| 接口地址是否正确 | OpenAI 格式 `https://api.deepseek.com`；Anthropic 格式 `https://api.deepseek.com/anthropic`；不要加多余字符 |
| 是否重启了工具 | 配置文件或环境变量修改后，必须完全退出并重新打开工具 |
| 网络是否正常 | 能访问 DeepSeek 官网就一般没问题；报错信息可对照官方「错误码」页面（`/zh-cn/quick_start/error_codes`） |

补充：通义灵码、文心快码、CodeGeeX、腾讯云代码助手 CodeBuddy 等国内工具通常自带模型套餐，是否支持自填 DeepSeek API 要看各家设置页；如果你希望“用 DeepSeek 模型来驱动编程助手”，上面三款（Codex、OpenCode、Claude Code）是 DeepSeek 官方提供接入教程的现成选择。

### 5.5 用 AI 工具修改英语刷题机：特别提醒

- 让工具**先读项目根目录的 README.md 和 AGENTS.md**（里面写明了技术栈、固定验收命令，以及“不得提交 APK / 数据库 / 签名”等规则）。
- 每次改动后必须完成 5.2 节的三条构建命令，生成新 APK 才能装到手机；内测版使用固定签名，新版本 `versionCode` 必须递增，否则无法覆盖安装。
- **一次只改一件事**；改完由你快速试核心功能（做题、提交、单词本、AI 功能），有问题立刻让 AI 回滚。
- API Key 只填在应用「模型与 API」页面，不要让 AI 工具把密钥写进代码或提交到仓库。
