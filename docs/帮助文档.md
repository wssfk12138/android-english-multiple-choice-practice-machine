# 英语刷题机 Android 使用帮助

> 本文档随应用离线提供。具体版本号以“更新与远程题库”页面为准。

## 首次使用

1. 进入“设置 → 模型与 API”，添加一个 OpenAI 兼容接口。
2. 填写 API Base URL 和 API Key，保存后同步模型。
3. 选择默认模型并测试连接。
4. 返回首页选择当前题库配置和练习入口。

API Key 只保存在 Android 系统安全存储中，不进入题库、诊断日志或源码。使用远程模型时，供应商可能接收你主动提交的聊天内容、错题分析数据或待翻译单词。

## 竖屏界面

- 底部导航分为“首页、笔记、AI、设置”。
- 首页按当前题库实际内容显示听力、完形、阅读和 Part B 入口。
- 做题页采用上方文章、下方题目与选项的独立滚动区；拖动中间分隔条可改变两区占比。
- 顶部紧凑工具栏包含返回、计时/暂停和答题卡。答题卡中可查看完成情况并提交单篇或整卷。
- “笔记”中集中放置错题本和单词本；题库导入、回收站、更新等管理功能收纳在“设置”。

## 题库与练习

- 支持 DOC、DOCX、文本型 PDF 和 ESQ 1.0/1.1 导入。
- Word/PDF 导入可使用模型辅助定位题目与答案，并在逐字段草稿校对后批准入库。
- 支持多个题库配置；导入前选择目标配置，首页和错题本跟随当前配置切换。
- 支持按年份整卷练习、随机抽取整篇、听力单刷，以及完形、阅读和 Part B 专项练习。
- 可在开始前选择是否计时。计时听力不允许拖动进度，非计时听力允许自由定位。
- 提交前若有未答题，系统会阻止提交并定位到对应题目。
- 可选择打乱选项，降低反复练习时记住答案位置的影响。

## 错题本

- 按年份、篇目和历次重做快照组织错题。
- 支持篇目重做、批量删除与七天回收站恢复。
- 提交后只显示错误作答，不直接展示正确答案。
- AI 分析只输出能力短板和复习建议；结果保存在本地，完成下一次同篇错题重做后才允许重新分析。

## 单词本

- 做题时长按文章、题干或选项中的单词即可加入单词本，当时不显示翻译。
- 退出答题页或进入单词本后，后台会自动处理待翻译词条。
- 词条可包含常用义、语境义、记忆提示以及可选的同义词、反义词和形近词辨析。
- 同一单词遇见两次及以上会标为高频词；首页词汇回顾优先展示近期和高频内容。
- 支持按复习计划完成正式复习，也可选择额外巩固，不影响当天正式计划。

## AI 助手与模型

- 可保存多套 API 配置，分别启用或停用。
- 同步接口可用模型后，可决定哪些模型出现在助手选择器中。
- AI 助手保存本地对话历史；默认提示词不会主动泄露标准答案。
- 题库智能标注可按本次导入、年份或全部题库处理，并允许人工校正和锁定标签。

## 更新、日志与隐私

- 点击“检查程序更新”后，系统在后台自动尝试可用更新通道，不展示或要求手动选择来源。
- APK 下载后会校验文件大小和 SHA-256，再交给 Android 系统安装器确认，应用不会静默安装。
- 诊断日志只保存在本机，不会自动发送。你可以查看、复制、导出或通过系统分享交给开发者。
- 诊断日志会过滤密钥、题库正文、答案正文、个人学习记录和本机完整路径。

## 常见问题

### 没有可用模型

检查 API 配置是否已启用、Base URL 和 API Key 是否正确，再同步模型并选择默认模型。

### 单词一直等待翻译

退出答题页或打开单词本以启动后台翻译；仍未完成时检查默认模型连接和账户余额。

### 扫描版 PDF 无法导入

扫描图片或严重水印且没有可靠文字层的 PDF 需要先做 OCR 或人工整理。程序不会把 OCR 失败伪装为成功导入。

### 更新无法下载

确认网络可用后重试。系统会自动切换已配置的备用通道；安装时仍需在 Android 系统界面确认。

## 问题反馈

请使用帮助页或设置页底部的“问题反馈”按钮打开反馈页面。提交问题时可附上脱敏诊断日志，但不要发送 API Key、完整题库正文或个人学习记录。
